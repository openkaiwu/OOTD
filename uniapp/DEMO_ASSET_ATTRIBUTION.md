# 模拟衣橱素材来源与许可

`src/static/demo-wardrobe` 仅用于本地产品原型、功能测试和内部 APK 验收。50 条女士流行款记录会复用这些素材；数据本身位于 `src/domain/demo.ts`。

下载脚本固定保存缩略图，避免把 Commons 原始大图打进安装包。若将这些图片用于公开发行，请再次检查来源页的最新权利说明，并在 App 的“关于/素材许可”中保留本表。
