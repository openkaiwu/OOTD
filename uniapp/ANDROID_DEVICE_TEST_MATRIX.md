# 正式 DCloud APK 真机验收矩阵

本表只用于 `com.wearing.ootd.internal` 的正式 DCloud APK；`com.wearing.ootd.preview` 仅用于核对界面版式，不能替代原生能力验收。

## 当前状态

- 360 / 390 / 412px 代码布局：已通过 H5 / APK 预览验收。
- Android 8 / 11 / 14 真机：待测；当前 ADB 未连接设备。
- 系统大字体：待正式真机测试。
- 阻塞项：DCloud Android 离线 SDK、应用 AppID / 离线 AppKey，以及至少一台已开启 USB 调试的 Android 设备。

## P1 可用性与异常用例

| ID | 用例 | 通过标准 |
| --- | --- | --- |
| B01 | 系统字体最大 | 无关键文本截断；按钮仍可点击；可滚动到主操作 |
| B02 | TalkBack | 核心按钮、收藏、方案选择和输入框读出名称与状态 |
| B03 | 触控区 | 核心交互热区不小于 44 × 44 CSS px |
| B04 | 弱网 / 天气超时 | 8 秒内回退；展示缓存新鲜度或离线状态 |
| B05 | 无网 | 衣橱、推荐和历史可用；天气说明清晰 |
| B06 | 后台回收 | 图片处理草稿可恢复；未产生半写入元数据 |
| B07 | 损坏图片 | 单件提示异常，不阻塞其他衣物和推荐 |
| B08 | 低存储 | 保存失败有明确提示；旧文件未先删除 |
| B09 | 200 件衣物 | 搜索交互流畅；列表只加载缩略图 |
| B10 | 连续操作 30 分钟 | 无崩溃、黑屏、明显内存恶化或数据丢失 |

每台设备保存：设备型号、Android 版本、逻辑分辨率、字体缩放、APK SHA-256、证书 SHA-1、用例结果、失败截图/录屏和可复现步骤。P0 阻塞问题必须归零后才能将 `0.1.0` 标记为内测版。
