# OOTD UI/UX 审计与本轮处理

审计范围：首页、衣橱、穿搭推荐、个人中心的移动端主流程及共享组件。

## 已处理

1. **P1：主题串色。** 多个共享卡片、图片底色和主按钮写死为粉紫/白色，导致 INS 与森系只更换了少数颜色。本轮将这些位置替换为语义主题变量。
2. **P1：主题的形状语言没有区分。** 三套主题原本几乎使用同样的圆角与阴影。本轮为 INS 使用利落小圆角和浅阴影，梦幻少女使用柔和圆角，森系使用舒展圆角与温和阴影。
3. **P2：视觉焦点不稳定。** 衣物与穿搭图片使用固定粉色底。本轮将其统一到主题图片表面，让图片优先于装饰色。
4. **P2：交互一致性。** 保留现有 88rpx 触控高度、选中状态、加载状态和减少动效支持；未改变路由、数据和主操作位置。

## 验收标准

- 切换三个主题后，首页、衣橱、穿搭推荐和个人中心的结构与功能一致。
- 主题差异可从画布、圆角、阴影、主按钮、图片容器和图标背景立即辨识。
- 任一主要按钮最小高度不低于 88rpx；选中态不能仅依赖颜色。
