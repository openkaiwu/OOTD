# Android 0.1.0 内测发布清单

## 自动门禁

- [ ] 使用 Node 20 LTS 执行 `npm run type-check`。
- [ ] 单元测试全部通过，推荐/识别/统计/存储核心分支覆盖率不低于 80%。
- [ ] `npm run build:h5` 成功。
- [ ] `npm run build:mp-weixin` 成功。
- [ ] `npm run build:app` 成功，且 HBuilderX 可加载 App 资源。

## 真机矩阵

- [ ] Android 8 低性能设备或等效模拟器。
- [ ] Android 11。
- [ ] Android 14。
- [ ] 当前最新 Android。
- [ ] 相机、相册、定位分别验证首次允许、拒绝、永久拒绝、去设置后恢复。
- [ ] 无网、弱网、天气超时、缓存过期和示例天气。
- [ ] 后台回收、处理中退出、草稿恢复、损坏图片、存储不足。
- [ ] 200 件衣物：搜索 <100ms、本地生成 <1s、列表只加载缩略图。
- [ ] 连续使用 30 分钟无崩溃。

## 数据与业务闭环

- [ ] 重启后衣物原图和缩略图仍可读。
- [ ] 批量队列单项失败不影响其他图片。
- [ ] 删除 5 秒内可撤销；超时后元数据和文件正确清理。
- [ ] 三个推荐入口共用同一上下文，结果与理由一致且三套有差异。
- [ ] 喜欢、不喜欢、保存、已穿会改变偏好或统计。
- [ ] JSON 备份导入不会静默覆盖相同 ID。
- [ ] Android 图片归档在另一台测试设备可恢复；失败时单品保留并标记待补图片。
- [ ] 清空操作完整且无法被误触一次完成。

## 云打包与分发

- [ ] 包名 `com.wearing.ootd.internal`。
- [ ] 版本 `0.1.0`、versionCode `1`、minSdk `26`。
- [ ] 使用 HBuilderX 正式版正常云打包，不使用标准/自定义调试基座。
- [ ] 测试签名、DCloud 账号和 AppID 凭据未进入 Git。
- [ ] 已记录证书 SHA-1/SHA-256 指纹。
- [ ] 独立 APK 可安装、升级、冷启动和卸载。
- [ ] 3～5 名测试者收到内测说明与问题反馈模板。
- [ ] 数据丢失、图片重启失效、无法生成、权限死循环、清空不完整、APK 无法安装均为 0。

## 当前外部验证状态

本机未安装 HBuilderX、JDK/签名工具和 Android Platform Tools，也没有 DCloud 打包凭据及仓库外测试签名。因此 APK 云打包、证书指纹和真机矩阵必须在发布环境完成；不得把 CLI 的 App 资源误称为可安装 APK。
