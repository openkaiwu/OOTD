# 实施状态

## 已落地

- M0：正式 uni-app Vue3/TypeScript 工程、Node 20 基线、Pinia、H5/App/微信命令、类型检查和 Vitest。
- M1：Diamond Glass Token、四 Tab、安全区、导航、Toast/弹窗/空态/错误态、Repository 与端口契约。
- M2：媒体批量队列、1600px/82% 原图和 360px 缩略图目标、持久化、草稿、规则建议、校对保存、衣橱维护与删除撤销。
- M3：Open-Meteo、缓存/超时/离线回退、条件选择、评分推荐、3 套结果、反馈/保存/分享/换批/已穿。
- M4：偏好、负反馈原因、指定单品、穿着统计、版本化 JSON 备份合并和本地诊断日志。
- M5 软件部分：隐私说明、发布门禁、异常防护、H5 和微信生产构建。

## 需要发布环境验收

- HBuilderX 正常云打包与独立 APK 安装。
- Android 8/11/14/当前版本真机权限、生命周期、低存储和 30 分钟稳定性测试。
- 仓库外测试签名生成与证书指纹记录。
- Android JSON+图片 ZIP 归档的文件系统适配与跨设备恢复。目前 UI 只开放已验证的版本化 JSON，并明确提示图片路径限制。

上述项目依赖本机当前不存在的 HBuilderX、Android 工具链、DCloud 凭据、测试签名和测试设备，因此保持为发布门禁，而不是用未验证实现冒充完成。
