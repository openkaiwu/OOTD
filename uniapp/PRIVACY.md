# 隐私说明（内测版 0.1.0）

## 数据保存

衣物照片、衣物标签、偏好、穿搭、反馈、穿着记录和本地诊断事件默认只保存在当前设备。本版本没有账号、广告、云同步、远程行为分析或服务端 AI。

## 权限

- 相机：仅在用户主动选择“拍照添加”时申请，用于拍摄衣物。
- 相册：仅在用户主动选择“从相册添加”时调用，用于选择衣物照片。
- 定位：仅在用户主动选择“使用当前位置”时申请，用于查询当地天气；启动阶段不会弹出定位权限。
- 网络：仅用于 Open-Meteo 天气预报和城市搜索。
- 震动：用于收藏、反馈等轻触反馈。

拒绝定位后仍可手动搜索城市或使用明确标记的示例天气。应用不会静默使用北京或其他默认城市。

## 第三方服务

天气与城市搜索调用 Open-Meteo。请求包含查询所需的城市关键词或经纬度，不包含衣物照片、偏好、昵称或穿搭记录。

## 导出与删除

用户可以在“我的 → 数据与存储”导出版本化 JSON、导入并按稳定 ID 合并，或通过双重确认清空本机数据。跨平台 JSON 不携带图片二进制；私有图片路径在另一台设备上可能需要重新补充。

本地诊断日志最多保留最近 300 条操作类型、时间和非敏感计数，不包含衣物照片、精确位置、城市搜索词或个人文本。
